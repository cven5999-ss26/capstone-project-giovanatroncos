Introduction

This dataset contains information on 63 Engineers Without Borders (EWB-USA) projects in Peru, with project start dates ranging from 2002 to 2025. Each row represents one project, and the 11 columns include the project name, online record link, responsible chapter, country, start date, completion date, end date, project status, project type, engineering discipline, and number of beneficiaries.The projects include 45 water supply projects, 5 sanitation projects, 5 structures projects, 4 agriculture projects, and 4 energy projects. The dataset records 57 completed projects and 6 active projects. Some fields have missing values, particularly engineering discipline and end date. For analysis in R, the total row, blank row, and filter notes should be excluded.These data can be used to examine EWB’s project portfolio in Peru, compare project types and chapter involvement, explore project timelines, and summarize reported beneficiaries.
